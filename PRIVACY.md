# Privacy Policy for Keyword Spider

Last updated: October 17, 2026

Keyword Spider is a browser extension that processes the visible text of a page selected by the user to extract and rank English keyphrases.

## Data collection

Keyword Spider does not collect, transmit, sell, share, or remotely store personal data, browsing history, page content, analytics, or usage information.

All extraction, ranking, animation, and export operations run locally in the user's browser. Page content never leaves the user's device.

Exported JSON and CSV files are created only when the user explicitly selects an export button. Those files are saved through the browser's normal download mechanism and are not accessible to the extension after download.

## Data retention

Keyword Spider does not retain page content or extracted results after the page is closed or refreshed. The extension does not operate a server or cloud database.

## Permissions

- `activeTab` provides temporary access only to the tab where the user invokes Keyword Spider.
- `scripting` allows the bundled spider engine to run after the user explicitly selects **Start Spider**.

Keyword Spider does not request persistent access to all websites and does not run automatically in the background.

## Third parties

Keyword Spider does not use third-party analytics, advertising services, tracking technologies, remote code, or external APIs.

## Children

Keyword Spider does not knowingly collect information from anyone, including children, because it does not collect or transmit user data.

## Changes

Any future change that affects data handling will be documented in this policy before release. The update date at the top of this document will also be revised.
