# Changelog

All notable changes to Keyword Spider are documented in this file.

The project follows [Semantic Versioning](https://semver.org/).

## [Unreleased]

### Added

- Privacy-safe synthetic demo page and a 1080 × 1080 MP4 recorder for product announcements and store media.

## [1.0.0] - 2026-10-17

### Added

- General English keyphrase extraction for articles, products, documentation, jobs, profiles, search results, and listings.
- RAKE-inspired ranking with title, heading, emphasis, frequency, metadata, position, and technical-dictionary signals.
- Generic interface-noise filtering and focused LinkedIn feed and job adapters.
- Animated top-to-bottom spider route for document and nested SPA scrolling.
- Ranked results panel with scores, categories, pause/resume, speed control, and JSON/CSV export.
- Completion sequence with a goodbye animation and a resting corner web.
- Chrome and Firefox Manifest V3 extension package.
- Optional Playwright demo runner, video recording, persistent external profiles, timeouts, and cleanup.
- Automated browser and popup tests.
